# Flutter Widgets Practice 📱

A Flutter project created to review and practice fundamental Flutter widgets and UI development concepts.

## 🎯 Project Goal

The main goal of this project is to refresh my Flutter knowledge, strengthen my understanding of basic widgets, and improve my skills in building user interfaces.

## 🛠️ Built With

- Flutter

## 📚 What I'm Practicing

- Basic Flutter Widgets
- Layouts using `Row` and `Column`
- UI composition and widget structure
- Styling, spacing, and alignment
- Building responsive and organized UI layouts

## ⚠️ Project Status

This project focuses on UI development and widget practice only. It does not include backend integration or complete application functionality.

## 🚀 Getting Started

1. Clone this repository.
2. Open the project in VS Code or Android Studio.
3. Run the following command:
   flutter pub get

4. Launch the application:
   flutter run
